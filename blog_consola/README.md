# Proyecto de Blog

Este proyecto consta en la construccion de una blog interactivo en donde se manejan post sobre cursos.

El archivo ejectubable es el main.py, este archivo va a ocupar los modulos y paquetes necesarios para funcionar.





## Estructura del Repositorio
```
blog_consola/
│
├── main.py
├── README.md
│
└── blog/
    ├── __init__.py
    ├── datos.py
    ├── menu.py
    ├── operaciones.py
    └── validaciones.py
```
